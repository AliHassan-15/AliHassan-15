## Engineering

Good engineering is when the code disappears behind the problem it solves. If someone else can understand it, extend it, and trust it months later without needing the author in the room, the job is done well.

1. Solve the real problem before writing code.
2. Build complete systems, not isolated features.
3. Let evidence guide decisions.

## Selected work

Confirmed public work only. Measured outcomes are not claimed here.

### [DeepMed — AI Healthcare Platform](https://github.com/AliHassan-15/DEEPMED-Testing)

Voice-first AI healthcare platform for patient intake before clinical consultation.

Team project (3 members). I served as Technical Lead, leading the overall technical direction while owning the system architecture, backend engineering, database design, API development, LLM workflow orchestration, AI integration, technical documentation, and the majority of testing and quality assurance.

Public evidence: testing and QA companion repository. Main source repository remains private due to university restrictions.

### [RouteWise ELD — Electronic Logging Device Platform](https://github.com/AliHassan-15/RouteWise-ELD)

Full-stack ELD platform for U.S. trucking operational workflows.

Primary Full-Stack Developer — backend architecture, Django backend, database design, business logic, APIs, frontend, and FE/BE integration.

### [Underwater Image Enhancement System](https://github.com/AliHassan-15/Underwater-Image-Enhancement-System)

AI-powered enhancement of underwater photographs with a full pipeline from training to a production-style web interface.

Sole Developer — dataset prep, model design, training, evaluation (PSNR/SSIM), Grad-CAM, FastAPI, React, end-to-end deploy architecture.

### [Codebase RAG — AI Developer Assistant](https://github.com/AliHassan-15/Codebase-RAG)

Natural-language questions over a codebase with answers grounded in source files.

Primary Developer — ingestion, embeddings, retrieval, context management, LLM integration, end-to-end RAG architecture.

### [Stellar Web Manager — AI Project Management Platform](https://github.com/AliHassan-15/Project-Management-System)

Collaborative project management with AI-assisted productivity in workflows.

Primary Developer — full-stack architecture, MERN, authn/authz, collaboration, analytics, AI assistant, APIs, DB architecture.
