# Cross-surface continuity (M9)

**Status:** Construction document  
**Authority:** Engineering implementation — not Product Bible  
**Milestone:** M9

## Intent

EOS has two public surfaces. M9 does not add domains. It makes the existing
system feel inevitable: GitHub entrance → Companion → Product Archive → case
study → return.

## Continuity contracts

| Concern | Rule |
|---------|------|
| Identity | Both surfaces read `content/` via meaning loaders — one voice |
| Labels | Chrome uses `ROUTE_ORIENTATION` labels (`Companion`, `Product Archive`) |
| Entrance | Return/Entrance links use `identity.githubEntranceUrl` |
| Metadata | Title / description / Open Graph / Twitter / canonical agree per route |
| Motion | Reuse M7 reveal/presence only — no page-local choreography |
| Honesty | Missing/Deferred stay Missing/Deferred (M6) |

## Removal posture

Anything that exists only because portfolios usually have it, or that no longer
earns its keep (unused interaction helpers, unused disclosure motion, misleading
shell orientation), is removed in M9.

## Out of scope

Spatial, Audio, Research, Lab, Writing, Timeline, skills visualization, and new
routes remain later milestones.
