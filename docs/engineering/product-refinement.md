# Product refinement (M12)

**Status:** Construction document  
**Authority:** Engineering implementation — not Product Bible  
**Milestone:** M12 — Premium Experience Refinement

## Intent

No new features. Existing Companion surfaces were refined so the product feels
inevitable: quieter chrome, calmer motion, clearer reading rhythm, less visual
noise.

## Decision filter

Keep or change only when the change improves clarity, readability, consistency,
accessibility, or perceived quality. Otherwise remove.

## Changes (summary)

| Area | Refinement |
|------|------------|
| Header | Brand without underline; prefs as ghost Caption-weight controls |
| Links | Secondary underline on hover only |
| Motion | No Reveal on Dividers; softer PagePresence; shorter stagger/distance |
| Case study | Single evidence rule; quieter types; tighter field padding |
| Archive | Editorial titles; caption tier labels |
| Atmosphere | Neutral wash; lower opacity |
| Topology | Softer orthographic hint; list remains primary |
| Shell / footer | Matched vertical rhythm |
| Interaction | Press nudge removed (opacity only) |

## Removals

- Divider entrance motion
- Accent-tinted atmosphere
- Secondary button weight on Theme / Sound
- Permanent secondary underlines in chrome
- Heading-as-caption fight in archive tiers

## Out of scope

Lab, Writing, Research, Career, dashboards, stats, particles, new routes,
redesign-as-replacement.
