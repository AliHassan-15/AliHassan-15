## 0. Purpose

**Why.** Discovery owns whether evidence exists. Design Language and Content Presentation govern visual and presentation law. Surfaces apply evidence without inventing it. Without an assets system, EOS invents imagery, upgrades Deferred gaps, or replaces proof with atmosphere.

**Specification.** This document specifies the EOS Asset System while remaining completely implementation-independent. It governs engineering assets as communicative evidence: selection, categorization, pairing with content, quality, honesty, review, and evolution. It applies Documents 03, 05, 09, 15, 21, 22, 23, and 24; it does not redefine them. It never governs Discovery ownership. It never invents missing assets. It never upgrades Deferred evidence into shipped evidence. It never defines implementation, rendering, tooling, or file formats. Exact asset inventories, screenshot inventories, diagram inventories, illustration inventories, recording inventories, media libraries, and proof packs remain **Deferred**. Deferred gaps are never filled by fashion catalogs or invented assets presented as locked.

**Failure Conditions.** Asset systems that contradict Documents 00–24. Redefinition of Discovery, Design Language, Content Architecture, UI Constitution, Content Presentation, README System, Companion Experience, or Content & Writing System. Invented assets presented as present. Deferred upgraded to shipped without Discovery. Construction-bound recipes treated as the asset system itself.

## 18. Asset Review

**Why.** Assets without review become imagery culture. Review enforces Documents 00–25.

**Specification.** Asset system review must answer:

1. Does this obey Documents 00–25?  
2. Does it apply Documents 03, 05, 09, 15, 21, 22, 23, and 24 without redefining them?  
3. Does Discovery support this asset’s existence grade?  
4. Does the asset improve engineering understanding rather than decorate?  
5. Are Missing and Deferred states honest?  
6. Does README asset use stay at entrance depth?  
7. Does Companion asset use avoid résumé costume and false shipped claims?  
8. Has any Deferred inventory been invented?  
9. Would this asset still deserve to remain in five years?

Failing any question blocks acceptance until corrected or explicitly Deferred with owner.

**Failure Conditions.** Review skipped. Failed questions accepted as taste. Deferred invention treated as pass. Decorative assets accepted as evidence.
