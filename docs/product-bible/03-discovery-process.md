Purpose of Discovery

This document does NOT design the product.

It discovers the product.

It defines WHY EOS exists,
WHO it exists for,
WHAT problems it solves,
WHAT experience it should create,
and HOW success will later be evaluated.

Discovery intentionally avoids discussing:

• layouts

• UI

• typography

• colors

• motion systems

• components

• implementation

• frameworks

• animations

Those belong later.
